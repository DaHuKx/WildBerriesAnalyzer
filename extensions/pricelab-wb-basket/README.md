# PriceLab — артикулы корзины WB

Расширение Chrome / Edge (Manifest V3): при открытии корзины Wildberries собирает артикулы товаров, прокручивает список для lazy-load и даёт скопировать их в буфер для PriceLab или бота.

## Установка (распакованное)

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → выберите папку  
   `extensions/pricelab-wb-basket`.
4. Откройте https://www.wildberries.ru/lk/basket (нужно быть авторизованным).

На странице корзины появится панель PriceLab. На иконке расширения — счётчик артикулов; в popup можно скопировать список ещё раз.

## Примечания

- Работает только на десктопе в браузере.
- Если вёрстка WB изменится, обновите селекторы в `extract.js`.
- Для установки иконки уже лежат в `icons/`.
