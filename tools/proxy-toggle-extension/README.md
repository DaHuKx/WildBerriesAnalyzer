# Proxy Toggle — расширение Chrome / Edge

Переключает HTTP-прокси в браузере: IP, порт, логин, пароль.

## Установка (режим разработчика)

1. Откройте `chrome://extensions/` (или `edge://extensions/`).
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → папка `tools/proxy-toggle-extension`.
4. Нажмите на иконку расширения → введите данные прокси → **Включить**.

## Использование

| Поле | Пример |
|------|--------|
| IP | `pool.proxys.world` или `194.110.14.110` |
| Порт | `10000` |
| Логин | `user432766o46375r701560` |
| Пароль | `••••••` |

- **Включить** — весь трафик Chrome идёт через прокси.
- **Отключить** — прокси сбрасывается, используется обычное подключение.

Настройки сохраняются: после перезапуска браузера прокси останется включённым, если не отключить.

## Для Ozon

1. Включите прокси в расширении.
2. Откройте https://www.ozon.ru/ — страница должна загрузиться без «Похоже, нет соединения».
3. Скопируйте cookie из DevTools → в `ozon-scraping-auth.json` на VDS с тем же `proxyUrl`.

## Ограничения

- Только **HTTP-прокси** (как у proxys.world).
- SOCKS5 этим расширением не поддерживается.
- Работает в Chrome и Edge (Chromium). Firefox — другой API.
